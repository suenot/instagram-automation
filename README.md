# instagram-automation

This private project will provide a Camoufox-based CLI for publishing Instagram Reels, photos, and carousels from a selected account. It is designed for calls from other services; those services own scheduling and queues.

**Status:** design and repository setup. `igpub` is not implemented yet, and this repository cannot publish content. The reviewed [Instagram plan](https://gitlab.com/reforms-lab/root/-/blob/main/docs/publishing/instagram.md) and [shared publishing contract](https://gitlab.com/reforms-lab/root/-/blob/main/docs/publishing/contract.md) define the implementation and verification gates. A real post requires a chosen account, media, caption, and live UI verification.

Version: see `VERSION`. Changes are recorded in `CHANGELOG.md`.
